# AGENTS.md

This repo is the **source of truth** for skills shared across my projects.

- Skills: `skills/<name>/SKILL.md`, [Agent Skills spec](https://agentskills.io/specification) (directory name == `name`, kebab-case).
- Keep skills project-agnostic: refer to the consuming repo's `AGENTS.md` instead of hardcoding its commands, paths, or stack.
- Public repo: never add secrets, internal URLs, or client/project-specific details.
- Distribution and update flow: see `README.md`.
