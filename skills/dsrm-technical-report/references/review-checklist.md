# 送審前檢核表

逐項勾選；任何一項答「否」，先修正或在限制中據實說明，再送審。

## 結構與方法

- [ ] 第 10 條的四項內容各有對應的章（學位用途）；章節對應表放在研究方法章。
- [ ] 明寫 DSRM 的切入點；產物先存在者，寫出後見之明的偏差。
- [ ] 每個目標都由問題的某一面推出，且可以被評估。
- [ ] 每項主要設計決定都說出它回應哪個目標，以及拒絕了哪些替代方案。
- [ ] 展示一章說明實例的情境、規模，以及它離真實使用多遠。

## 評估

- [ ] 每次評估都標出 FEDS 的兩個維度（形成或總結 × 人工或自然）。
- [ ] 總結性評估有基線或對照；沒有基線的數字不寫成「提升」。
- [ ] 量測可重現：資料集、題庫、版本、日期、參數都寫明或附在附錄。
- [ ] 有效度威脅一節：內部、外部、建構效度至少各想過一次。
- [ ] 結論沒有超出評估的支持範圍；「機制已實作」與「目標已達成」分開寫。

## 貢獻

- [ ] 貢獻歸入四象限之一，並說明理由；不把例行設計寫成發明。
- [ ] 標出貢獻的抽象層次（實作、設計原則、設計理論）。
- [ ] 「學理分析具有重要具體之貢獻」能從報告本文指出是哪幾段（學位用途）。

## 引用與核對

- [ ] 每一筆文獻都核對過原文；書目記錄核對程度（全文、摘要、書目）。只讀過摘要的，正文不轉述其細節。
- [ ] 條文以全國法規資料庫現行版本核對，寫出法規名稱與條項款；修正中或未施行的條文註明。
- [ ] 他人的圖、表、架構說明都標出處（著作權法第 52、64 條）；改繪者註明「改繪自」。
- [ ] 自己先前發表或撰寫的內容（論文、專論、內部文件）重用時標出處，避免自我抄襲。
- [ ] 所有數字、版本、日期能指回原始來源；沒有來源的數字刪掉。

## 倫理與法遵

- [ ] 生成式 AI 的使用依學校規定揭露；沒有規定時在方法章或附錄寫明工具、用途與核對者。
- [ ] 涉及人類研究參與者者，已依學校研究倫理審查委員會規定處理，核准或免審文號寫進方法章。
- [ ] 報告中的真實資料、截圖已去識別化；客戶或合作機關的未公開資料已取得同意或移除。
- [ ] 含機密、專利申請中或依法不得提供的內容者，已在學位考試前決定是否申請延後公開。
- [ ] 送存國家圖書館的電子檔為可檢索 PDF、無開啟密碼；授權書依學校流程簽署。
